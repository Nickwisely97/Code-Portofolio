# Principal Component Analysis — PCA (concept demo)

Standalone demonstration of PCA mechanics on the sklearn digits dataset: scree plot for choosing component count, and a before/after comparison of a downstream classifier's accuracy and training time with vs. without PCA.

**Status:** flagged for future integration into a full applied "Segmentation" project (RFM + PCA + K-Means) — see the repo root README. Kept standalone here for now rather than moved, since that merge is a separate, not-yet-started piece of work.

## How to run
Open `code/pca_analysis.ipynb`. Plots saved to `result/`.
