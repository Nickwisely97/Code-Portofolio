# Tournament Bracket — Score Tracker

A lightweight standalone HTML/JS scoring utility (`code/index.html`) — not a modeling notebook, so it has no `data/`, `result/`, or `requirements.txt`.

**Planned upgrade:** turn this into an actual optimization project — a Swiss-system tournament pairing optimizer (minimize rematches, balance opponent strength) using LP/constraint programming, which would map to the same Queueing/Staffing & Optimization skill as the Staffing Optimization project.

## How to run
Open `code/index.html` directly in a browser.
